# Practical 02 - Privacy Impact Assessment

## Aim
To perform a Privacy Impact Assessment for a hypothetical student attendance application.

## System
The application records student identity, attendance, device information and login activity.

## Procedure
1. Describe the system.
2. Identify personal data.
3. Identify processing purposes.
4. Identify privacy risks.
5. Rate likelihood and impact.
6. Define mitigation measures.

## Result
A PIA identifies privacy risks before deployment and maps each risk to a mitigation.
