# Practical 07 - Privacy-Enhancing Technologies

## Aim
To study and compare privacy-enhancing technologies (PETs).

## Technologies
- VPN
- Tor
- End-to-end encrypted messaging
- Encryption
- Access control

## Comparison

| Technology | Main purpose | Privacy benefit | Limitation |
|---|---|---|---|
| VPN | Encrypt traffic to VPN provider | Helps protect traffic on local networks | VPN provider can still observe metadata |
| Tor | Multi-hop anonymizing network | Reduces direct linkability of network activity | Slower and not perfect anonymity |
| E2EE | Protect message content | Provider cannot normally read message content in transit | Metadata may still exist |
| Encryption | Protect stored/transmitted data | Reduces unauthorized disclosure | Key management is critical |
| Access control | Restrict who can access data | Limits insider/unauthorized access | Poor configuration can weaken protection |

## Conclusion
PETs reduce particular privacy risks, but no single technology guarantees complete privacy.
