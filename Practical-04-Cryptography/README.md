# Practical 04 - Cryptography

## Aim
To implement basic cryptographic techniques for protecting information.

## Programs
1. Symmetric encryption using Fernet.
2. RSA asymmetric encryption.
3. SHA-256 hashing.
4. Digital signatures and signature verification.

## Install
```bash
pip install -r ../requirements.txt
```

## Important
Hashing is one-way; encryption is reversible when the correct key is available. Digital signatures provide authenticity/integrity and are not the same as encryption.
