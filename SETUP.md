# How to run the practicals

## 1. Install Python
Install Python 3.10+ and make sure `python --version` works in Command Prompt.

## 2. Create a virtual environment (recommended)

Windows:
```powershell
python -m venv .venv
.venv\Scripts\activate
```

## 3. Install dependencies
```powershell
pip install -r requirements.txt
```

## 4. Run a Python practical
Example:
```powershell
python Practical-04-Cryptography\hashing.py
```

Another example:
```powershell
python Practical-05-Data-Anonymization\k_anonymity.py
```
